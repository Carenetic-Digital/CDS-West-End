# Brand Colors — West End Dental Centre

Source: live site https://www.westenddentalcentre.com/ (teal CTA `#54add3`, Acumin/Roboto CDS theme).

The live brand teal is too light for body-sized text or white-on-teal buttons at WCAG AA. UI tokens are darkened from `#54add3` the same way Crestwood darkened `#008545` → `#00703a`.

| Role | Hex | Notes |
|------|-----|--------|
| Brand teal (live) | `#54add3` | Decorative accent, eyebrows, soft fills |
| Primary | `#1d6f8c` | Header, footer, dark bands, AA text/buttons on light surfaces |
| Primary deep | `#15566d` | Hover / gradient |
| Heading deep | `#0d3d4d` | Dark teal headings |
| Soft teal | `#b7d9e8` | Accents, soft surfaces |
| Text | `#1f1f1f` | Body copy |
| BOOK NOW (live) | `#54add3` | Rebuild uses AA-safe primary for buttons |
